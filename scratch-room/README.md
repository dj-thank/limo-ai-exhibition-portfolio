# Scratch Room publication candidate

依存なしの静的Web体験です。HTTPSの任意の静的hostへこのfolderをそのまま配置できます。スマートフォン／タブレット／PCのPointer EventsとWeb Audioで動作し、PWAとしてcacheできます。

音源はブラウザ内で生成するオリジナルの合成声とdrumだけです。録音、ファイルupload、外部API、Cookie、analytics、第三者音源はありません。

実装は `source[p(t)] × g(t) × gain`。円盤の左右が位置と速度、上下がcrossfaderです。fader edgeは2ms ramp。BABY、CHIRP、TRANSFORMはChopLab native版と同じ基本制御を示します。

現在はローカル配信・ブラウザE2E対象で、公開URLは未作成です。公開先とポートフォリオ導線は共通hub ownerが決めます。
